# features

Small tool, sharp edges.

multi-repo scan

Scans every git repo under your roots in parallel. 70 repos in about a second.

local-llm brief

Ollama writes a 3-line welcome-back: what you were doing, where to pick up, one next step. No cloud, no keys, no cost.

zero dependencies

Plain Node ≥18 + git. Nothing to audit, nothing to break, nothing to update.

state at a glance

Uncommitted files ✎, unpushed commits ↑, stashes ⚑, stale repos in red. The truth about your WIP, finally visible.

--json output

Machine-readable everything. Pipe it into your own scripts, dashboards, or morning routine.

fails soft

No Ollama running? Everything except the brief works fine. It just tells you and moves on.

# commands

One binary, two names: wip and wip-ai.

commandwhat it does
wipscan repos, show recent activity + AI brief
wip --allshow every repo, not just the top 10
wip --no-aiskip the Ollama brief (faster)
wip --jsonmachine-readable output
wip --days 7only repos active in the last n days
wip --model llama3.2pick a different Ollama model
wip --path ~/workone-off extra directory to scan

# config

Optional. Lives at ~/.config/wip-ai/config.json.

{
  "roots": ["~/Projects", "~/sites"], // folders of repos (default: auto-detected)
  "extraRepos": ["~/dotfiles"],    // repos outside your roots
  "ignore": ["node_modules"],      // directory names to skip
  "model": "qwen2.5:7b",           // Ollama model for the brief
  "ai": true,                      // master switch for the brief
  "max": 10                        // rows shown by default
}

# why

Three honest reasons.

01

Context switching is expensive

Especially with ADD, especially with many side projects. Reloading "where was I" costs real time and energy. wip makes it one command.

02

Local-first means private

Your repo names and commit messages never leave your machine. The brief runs on your own Ollama model, offline if you want.

03

Uncommitted work is invisible until it hurts

Dirty repos, unpushed branches, forgotten stashes: wip surfaces all of it before you lose an evening of work to a clean install.
